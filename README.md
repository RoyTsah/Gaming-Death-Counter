# 💀 Gaming Death Counter

A small gaming death counter made with Python and Tkinter.

I built this project to practice Python, creating a GUI and saving simple data locally.

## Features

- Add deaths
- Undo the last death
- Reset the counter
- Saves the death count locally
- Simple graphical interface
- Windows `.exe` version

## Built With

- Python
- Tkinter
- PyInstaller

## Run with Python

Run:

`death_counter.py`

## Windows Version

A standalone Windows `.exe` version was created with PyInstaller, so the program can also be used without starting the Python file manually.
